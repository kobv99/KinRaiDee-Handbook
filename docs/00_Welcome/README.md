# Welcome to KinRaiDee

This section is the required entry point for every engineer, AI coding agent, product contributor, and technical reviewer joining KinRaiDee.

## What KinRaiDee is

KinRaiDee is an AI-assisted cooking platform built around the user's real pantry. The product is intended to become a Kitchen Operating System rather than a static recipe catalogue.

The system should help users:

- know what ingredients they have;
- notice ingredients that should be used soon;
- decide what to cook from available ingredients;
- adjust recipes to their actual household needs;
- deduct consumed ingredients accurately;
- correct cooking records later without corrupting pantry data;
- plan shopping, nutrition, budgets, and future meals;
- eventually use an optional local AI agent without surrendering ownership of pantry data.

## Before changing code

A contributor must be able to answer:

- What user problem is being solved?
- Which existing workflow is affected?
- What data changes?
- Can the feature work offline?
- How will it be tested?
- What documentation or ADR must change?

When these answers are unclear, the task is not ready for implementation.
